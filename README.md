# 🎉 Evently

**Evently** is a modern Flutter event management application designed to help users discover, organize, and manage events with a clean and user-friendly interface.

The application was developed by **Eng. Omar Ahmed Ali** as a Flutter project under the supervision of **Mohamed Nabil**.

## ✨ Features

* 🚀 **Onboarding**

  * Introduction screens
  * Language selection
  * Theme selection

* 🔐 **Authentication**

  * Login
  * Register
  * Forget Password
  * Login with Google
  * Light & Dark Mode

* 🏠 **Home Screen**

  * Search for events
  * Browse upcoming events
  * Event categories
  * Add new events

* ❤️ **Favorites**

  * Add events to favorites
  * View favorite events

* 👤 **Profile**

  * Profile screen
  * Language settings
  * Dark / Light Mode

* 📅 **Event Management**

  * Add Event
  * Event Details
  * Edit Event
  * Select Date
  * Select Time
  * Event Description
  * Event Location

* 🔎 **Search**

  * Search for events quickly and easily.

* 🌐 **Localization**

  * English
  * Arabic

* 🌓 **Theme**

  * Light Mode
  * Dark Mode
